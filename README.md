# PriceCheckList
Projet de scraping, de traitement de données et d'analyse prédictive pour le site **Warframe Market (WFM)**. Successeur spirituel des anciens scripts (notamment PCL de Steffronté), il exploite la nouvelle **API V2** (GoLang) de la plateforme pour générer une base de données de prix ultra-légère, fiable et optimisée pour une interface web moderne.
